## SnapForge 0.9.0

- При растягивании и перемещении большой пустой прямоугольной рамки перерисовываются полосы вдоль её границ. Пустая середина больше не вызывает полную перерисовку экрана.
- Зум редактора через Ctrl + колесо учитывает величину прокрутки. Добавлена обработка жеста приближения; точка под курсором остаётся на месте.
- Карандаш обозначен значком карандаша. Одиночный клик оставляет точку; при рисовании в захвате сохраняется последняя точка мазка.
- В настройках доступны масштаб интерфейса 75–200%, скорость зума 25–200%, ширина панелей инструментов и свойств, скрытие панели свойств и слоёв. Есть отдельная кнопка сброса этих параметров.
- Панели редактора прокручиваются при нехватке высоты. Масштаб основного интерфейса не меняет окна установки и удаления.
- В настройках захвата можно выбрать цвет рисования и толщину линии. Существующие настройки загружаются без ручного переноса.

### Проверка производительности

В локальном CPU-тесте отладочной сборки, на изображении 3840×2160, серия из 20 растягиваний пустой рамки заняла в среднем около 18 мс на кадр вместо 873 мс при прежней перерисовке ограничивающего прямоугольника. Замер не включает вывод окна через GDI и не описывает скорость всех инструментов: большие залитые фигуры, размытие и пикселизация по-прежнему могут требовать обработки большой области.

### Файлы

- `SnapForge-Setup.exe` — установщик.
- `SnapForge.exe` — переносная версия и файл для автообновления.
- `snapforge-cli.exe` — консольная версия.
- `SHA256SUMS.txt` — контрольные суммы.
